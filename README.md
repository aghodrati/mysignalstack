# finance

A base for testing finance hypotheses with pandas + yfinance.

## Structure

- `finance/data.py` — fetches adjusted prices via yfinance, caches to `cache/` as CSV. `get_prices` for daily adjusted close; `get_open_close` for daily adjusted open + close together; `get_intraday_closes` for intraday bars (Yahoo limits 60m bars to ~2 years back, finer intervals to ~60 days).
- `finance/backtest.py` — generic rebalancing engine. You give it a `weight_func(date, prices_so_far) -> {ticker: weight}` and it simulates the strategy's equity curve. Optional `cost_bps`: round-trip transaction cost in basis points, charged on every rebalance (off by default).
- `finance/metrics.py` — CAGR, volatility, Sharpe, max drawdown, and a `summary_table` to compare strategies side by side.
- `finance/correlation.py` — pairwise return correlation over a lookback window, and a z-score of how far each pair's current cumulative-return spread sits from its own average over that window (a simple "has this normally-correlated pair diverged right now" signal).
- `finance/momentum.py` — `top_n_momentum_weight_func(lookback_days, n, direction)` builds a `run_backtest`-compatible weight_func: at each rebalance, rank a universe by trailing return and equal-weight the top ("best") or bottom ("worst") N. `picks_by_rebalance` returns the same picks as a table for inspection.
- `finance/dip.py` — `find_dip_trades(prices, benchmark, drop_pct, hold_days)`: for every single-day drop of more than `drop_pct`, a trade buying at that close and selling `hold_days` calendar days later, with the benchmark's return over the identical window for comparison.
- `finance/overnight.py` — `decompose_returns(opens, closes)` splits each day into its overnight (prev close → open) and intraday (open → close) return; `summarize` compounds both per ticker (aligned to the same valid dates before compounding, so `(1+overnight)*(1+intraday)-1` exactly reconstructs the true close-to-close total return).
- `finance/intraday.py` — `average_intraday_path(closes)` returns, per bar-of-day (e.g. hourly), the average return since that day's open across every day in the series — the "average shape of the trading day."
- `finance/pead.py` — `find_pead_trades(ticker, prices, benchmark, earnings, surprise_threshold_pct, hold_days, direction)`: classic post-earnings-announcement-drift — for every earnings report beating ("beat") or missing ("miss") estimates by more than the threshold, a trade buying at the close of the first trading day after the report and selling `hold_days` later, with the benchmark's return over the identical window.
- `finance/data.py` also has `get_insider_transactions(ticker)` — individual officer/director Form 4 filings (insider name, position, transaction text, date, shares, $ value) via yfinance, cached per-ticker like `get_earnings_history`; and `get_institutional_ownership(ticker)` / `get_major_holders(ticker)` — 13F-derived institutional + mutual fund holders (top ~10 of each, quarterly: % of shares outstanding held, $ value, % change since prior quarter) and the insiders/institutions % breakdown, also cached per-ticker.
- `finance/data.py` also has `get_stock_info(ticker)` (cached snapshot of yfinance's `Ticker.info` — valuation/growth/margin/price-target/short-interest fields), `get_recommendations_trend(ticker)` (analyst buy/hold/sell counts, current + prior 3 months), and `get_upgrades_downgrades(ticker)` (dated analyst upgrade/downgrade actions) — all feeding `finance/ranking.py`.
- `finance/ranking.py` — `build_factor_table` computes ~18 raw factors (growth, valuation, quality, momentum, sentiment, ownership/flow) per stock; `percentile_rank_table` converts each to a 0-100 rank within the universe; `category_scores` averages factors within each of 6 categories; `composite_score` combines categories into one score using caller-supplied weights (normalized to sum to 1).
- `finance/sec13f.py` — multi-quarter institutional ownership straight from SEC's bulk Form 13F structured datasets (unlike yfinance, which only exposes the latest quarter's % change). Resolves a ticker's CUSIP by matching company name against the aggregated data, then each quarter ranks filers by position size and takes the top 10 ("large institutional holders," same as yfinance's own table) — for each of those 10, computes that specific holder's own % change vs its prior-quarter position (100% if it wasn't a holder last quarter, matching yfinance's convention for a new position), and averages the 10, same methodology as yfinance, so the two numbers are directly comparable. Each quarterly dataset is ~100-400MB raw; only small aggregates (cusip-level and holder-level, a few MB each) are cached, and the raw files are deleted after use. Note: because this looks at individual filers' raw reported share counts rather than Yahoo's already-cleaned top-10 list, it's occasionally exposed to genuine data-entry errors in individual 13F filings (a filer's share count jumping by orders of magnitude between quarters) — a real example was found and confirmed during testing (AAPL, one filer's shares went from 35,852 to 205,722,672 with a value field that didn't match either).
- `finance/hypotheses/` — one file per hypothesis. Each exposes `main(start, end)`.
- `main.py` — CLI: `uv run main.py <hypothesis> [--start YYYY-MM-DD] [--end YYYY-MM-DD]`
- `app.py` — interactive Streamlit app. A "Return calculator" (ticker + start/end date → return) sits at the top of the sidebar, above the quick-pick categories. Nine tabs, most with their own "Since"/period control on their main page:
  - **Compare** — click to add/remove tickers from quick-pick categories in the sidebar (Biggest companies, Semiconductors, Software, Crypto, Metals, Oil & gas, Defense, Futuristic, S&P sectors) and/or type other tickers, then compare cumulative return against SPY (always a solid red line). Nothing is pre-selected — by default it shows just SPY.
  - **Correlations** — across every tracked ticker (equities + crypto + metals, excluding S&P sector ETFs and Defense), a correlation heatmap, a table of the most correlated pairs over a chosen lookback window, a beta-vs-S&P-500 table (formula shown inline), and a table of which correlated pairs have diverged most from their usual relationship right now (by z-score of the current return spread, formulas shown inline).
  - **Momentum** — tests "From date D, every T weeks, buy the N stocks with the best (or worst — toggle) trailing H-weeks gains, equal-weighted — does that beat holding the S&P 500?" D, T, H, N, the best/worst direction, and an optional round-trip transaction cost (bps, charged on every rebalance) are all adjustable; results shown as an equity-curve chart and CAGR/volatility/Sharpe/max-drawdown table against three benchmarks — the S&P 500, an equal-weight holding of the entire eligible universe, and a random-N-stock control averaged over 1000 simulated runs on the identical rebalance schedule (so you can tell whether the ranking itself adds value beyond "own N stocks on a schedule") — plus an always-expanded table of exactly which stocks were picked at each rebalance and the return that earned them the pick.
  - **Buy the dip** — tests "whenever a stock falls more than T% in a single day, buy it and sell it D days later — how does that compare to the S&P 500 over the same window?" Optional per-trade transaction cost (bps). Shows trade count, average return/excess return per trade, a naive sequential-compounding comparison, and the full trade list.
  - **Calendar** — three sections. "Overnight vs Intraday": for every stock in the universe plus SPY, compounds the overnight (prev close → open) and intraday (open → close) legs separately over the last 1 or 2 years, as a grouped bar chart. "Day of week": average daily return by weekday over that same period, for S&P 500 plus whichever tickers are picked in the sidebar. "Average intraday shape": the average return-since-open at each hourly bar, averaged across every trading day in a 3-month/6-month/1-year/2-year window, for any tickers you type in (limited to ~7 points/day since Yahoo only serves hourly bars this far back).
  - **PEAD** — the classic post-earnings-announcement-drift backtest: buy stocks whose earnings beat (or missed — toggle) their EPS estimate by more than X%, hold for T days (surprise% formula shown inline) — trade count, average/excess return per trade, and the full trade list (earnings date, surprise %, buy/sell dates and returns). Below that: a historical EPS-surprise curve for whichever tickers are picked in the sidebar, and a table of every universe stock's last 4 quarterly surprises plus its next scheduled earnings date.
  - **Insider** — raw officer/director Form 4 filings (SEC insider transactions, via yfinance), over a configurable lookback window (weeks), for whichever tickers are picked in the sidebar: filing/buy/sale counts, net $ bought vs sold, and the full filing list, per ticker. Below that, a filing-count/net-$ summary table for the whole equity universe, then a combined recent-activity table across the universe filtered to filings of at least $100k. Not a backtest — just visibility into who's buying or selling.
  - **Institutions** — 13F-derived institutional + mutual fund ownership, for whichever tickers are picked in the sidebar: average % of shares outstanding held and average % change since the prior quarter (across the ~10 largest institutional and ~10 largest mutual fund holders), the insiders/institutions % breakdown, and the "as of" filing date and full holder list per ticker. Below that, every stock in the universe ranked by largest average position change (up or down) since the prior quarter. An optional "load multi-quarter institutional history" checkbox pulls SEC's bulk 13F data instead (large one-time download per quarter, cached after) to show the top-10-institutional-holders' aggregate shares and % change (same methodology as yfinance's own number, so directly comparable) across as many past quarters as requested, per ticker.
  - **Ranking** — relative rank of every stock in the universe across six factor categories: Growth (revenue/earnings growth), Valuation (forward P/E, PEG, EV/revenue), Quality (operating/FCF margin — gross margin dropped, since many companies (Alphabet, Exxon, Chevron, ...) don't report a literal "gross profit" line), Momentum (trailing return, relative strength vs S&P, price vs 50-day-or-200-day moving average — selectable, relative volume), Sentiment (analyst price-target upside, revisions trend, net upgrades), and Ownership/Flow (institutional position change, insider buying/selling, short interest). Each raw factor is converted to a percentile rank within the universe, averaged equally within its category, then combined into one composite score using adjustable per-category weight sliders (default: equal). Shows the composite ranking table plus expandable raw-factor and percentile-rank tables for inspection.
  Run with `uv run streamlit run app.py`.
- `finance/universe.py` — static reference data backing the app: the quick-pick categories (including the S&P 500 sector → SPDR ETF mapping) and the SPY benchmark ticker.

## Existing hypotheses

- `momentum_top10` — each month, buy the top-10 stocks (from a fixed large-cap universe) by trailing 12-month return, equal-weighted. Compared against SPY buy & hold.

## Adding a new hypothesis

1. Create `finance/hypotheses/your_hypothesis.py` with a `main(start, end=None)` function.
2. For a rebalancing strategy: write a `weight_func(date, history_df) -> dict[ticker, weight]` and pass it to `run_backtest`.
3. For a simple "buy X vs Y at time T" comparison, you likely don't need `run_backtest` at all — just pull prices with `get_prices` and compare cumulative returns directly.
4. Register it in `HYPOTHESES` in `main.py`.

## Notes

- Prices are auto-adjusted (dividends/splits) via yfinance's `auto_adjust=True`.
- `cache/` and `output/` are gitignored — delete `cache/` to force fresh data.
